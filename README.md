## Функциональность

- Выбор типа БД при запуске:
  - In‑memory — данные не сохраняются после выхода
  - File database — данные сохраняются в data/movies.json
- Создание таблиц и добовление любых колонок
- Добавление записей
- Просмотр всех фильмов
- Поиск с фильтрацией
  - По добавленным колонкам
  - Для таблиц 'movies':
    - по id 
    - по названию (если есть данная колонка)
    - по году (если есть данная колонка)
    - по жанру (если есть данная колонка)
    - по рейтингу (если есть данная колонка)
    - по минимальному рейтингу (если есть колонка: rating)

## Обработка ошибок (для таблицы 'movies')

· Год от 1900 до 2026
· Рейтинг от 0 до 10
· Запрет дубликатов id
· Название и жанр не могут быть пустыми
· Ошибки работы с файлами (отсутствие, повреждённый JSON, ошибки ввода-выводы) обрабатываются

