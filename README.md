## Функциональность

· Добавление фильма (id, название, год, жанр, рейтинг)
· Просмотр всех фильмов
· Поиск с фильтрацией:
  · по id
  · по названию
  · по году
  · по жанру
  · по минимальному рейтингу

## Обработка ошибок

· Год от 1900 до 2026
· Рейтинг от 0 до 10
· Запрет дубликатов id
· Название и жанр не могут быть пустыми
