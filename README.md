# Лабораторная работа №2 — База данных «Фильмы»

**Студент:** Колесникова Анастасия Сергеевна  
**Группа:** M60-107БВ-25  

## Структура проекта

- src/db/__main__.py — точка входа
- src/db/tui.py — консольный интерфейс
- src/db/backend/__init__.py
- src/db/backend/memory.py — in‑memory БД (CR)

## Функциональность

- Добавление фильма (id, название, год, жанр, рейтинг)
- Просмотр всех фильмов
- Поиск с фильтрацией (id, название, год, жанр, рейтинг)
- Выход из программы

## Обработка ошибок

- Год: от 1900 до 2026
- Рейтинг: от 0 до 10
- Запрет дубликатов id

## Запуск

python -m src.db
